Pronto para começar?

Sua próxima partida está a um comando.

No Fedora, um único comando baixa, compila e instala o Cartridges no seu usuário.

curl -fsSL https://raw.githubusercontent.com/zonaro/cartridges/main/install.sh | bash

O instalador cuida das dependências e remove os arquivos de compilação ao terminar. Depois, abra Cartridges pelo menu de aplicativos.

FAQ

Dúvidas antes de apertar Play?

O Cartridges substitui meus launchers?

Não. Ele reúne seus jogos e abre cada título pela origem correta. Você ganha uma biblioteca única sem perder o que já usa.

Preciso usar o Game Mode?

Não. O aplicativo funciona normalmente no desktop. O Game Mode é uma opção extra para quem quer uma experiência de sofá.

Meus jogos são enviados para algum serviço?

Não. Sua biblioteca fica na sua máquina. Serviços de imagens e metadados só são consultados quando você os ativa.

Funciona sem controle?

Sim. Mouse e teclado funcionam no desktop; o controle é uma opção especialmente confortável no Game Mode.

O Game Mode muda meu desktop?

Não. Ele roda em uma sessão separada. Ao sair, você volta à tela de login e pode entrar no desktop normalmente.

Quais sistemas são suportados?

O aplicativo é voltado ao Linux. A instalação da sessão dedicada do Game Mode atualmente é preparada para Fedora.
